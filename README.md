# Online Grocery Store

A simple **Python and MySQL** project for managing a grocery store.
It allows users to add products, view and search products, update stock, 
register customers, place orders, and generate bills.

## Features

- Add and view products
- Search products
- Update stock
- Register customers
- Place orders
- Generate bills
- View order history

## Tech Stack

- Python
- MySQL
- PDBC (`mysql-connector-python`)
- Git & GitHub
